# Amazon Phone Market Analysis Dashboard

An interactive Power BI dashboard analyzing 319 Amazon phone listings,
covering pricing, sales volume, ratings, offers, and product badges
(Best Seller, Amazon's Choice, Prime, Climate Pledge Friendly).

## Dashboard Pages
1. **Overview** – project summary and key KPIs
2. **Sales Dashboard** – sales volume by price, rating, and discount level
3. **Product Analysis** – average prices, ratings, offers, and offer price gaps
4. **Insights** – badge distribution and key takeaways

## Key DAX Measures
- Average Product Price, Average Star Rating
- Total Sales Volume, Sales per Product
- Number of Offers
- Best Sellers Count vs Amazon's Choice Count
- Offer Price Difference (original vs minimum offer price)
- Climate Friendly %
